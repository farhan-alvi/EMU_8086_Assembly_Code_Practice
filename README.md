# COA 8086 Assembly Code Practice

A collection of 8086 Assembly Language practice programs developed and tested using **EMU8086** as part of my **Computer Organization and Architecture (COA)** course.

## Topics Covered

* Data movement and basic instructions
* Arithmetic operations
* Logical and bitwise operations
* Conditional and unconditional jumps
* Comparisons and the `TEST` instruction
* Loops and control flow
* Shift and rotate instructions
* Bit manipulation
* Character and string manipulation
* Interrupts using `INT 21H`
* Other 8086 Assembly practice problems

## Tools

* **EMU8086**
* **8086 Assembly Language**
